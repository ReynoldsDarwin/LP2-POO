📚 Sobre el Repositorio

Este repositorio contiene ejemplos y ejercicios prácticos de Programación Orientada a Objetos (POO) en Python, desarrollados durante el curso de Lenguaje de Programación II.

El objetivo es mostrar conceptos clave de POO como encapsulamiento, herencia, polimorfismo y relaciones entre clases, aplicados en distintos contextos y problemas.

Cada carpeta del repositorio contiene ejemplos bien documentados y ejercicios que demuestran la aplicación práctica de estos principios fundamentales de la programación orientada a objetos.

🚀 Proyectos

Calculadora Estadística

Este script funciona como una herramienta automatizada para el análisis de datos. Permite calcular medidas estadísticas clave como media, mediana, moda, varianza y desviación estándar a partir de un conjunto de datos proporcionado por el usuario.

Ver en el Repositorio

Conoce tu Signo del Zodiaco

Este programa implementa una herramienta de identificación astrológica personalizada que procesa la fecha de nacimiento del usuario. Utiliza la clase Persona para estructurar la información y validar los datos ingresados, comparando el día y mes contra un conjunto de rangos predefinidos para determinar con precisión el signo zodiacal correspondiente y presentar un resultado individualizado.

Ver en el Repositorio

Cubo con Imagenes en 3D

Visualización 3D interactiva de un cubo con OpenGL. Carga imágenes como texturas en cada cara, aplica iluminación y transparencia. Permite rotar con teclado/mouse y ajustar zoom con la rueda de desplazamiento.
